# Convolutional Neural Network (CNN) Image Classification Projects

This repository showcases two distinct image classification projects using Convolutional Neural Networks (CNNs) implemented in Python with TensorFlow/Keras.

## Projects Included

1.  **CIFAR-10 CNN Dropout Comparison:** Explores the impact of dropout regularization on a CNN classifying images from the CIFAR-10 dataset.
2.  **Intel Image Classification:** Analyzes and classifies natural landscape images from the Intel Image Classification dataset using various ML and DL techniques, culminating in a multiclass CNN.

---

## Project Overview

This repository serves as a portfolio of practical applications of CNNs for image classification tasks. It covers:

-   Data loading and preprocessing.
-   Model building with TensorFlow/Keras.
-   Experimentation with regularization techniques (Dropout).
-   Analysis of different datasets (CIFAR-10, Intel Image Classification).
-   Model evaluation metrics (accuracy, confusion matrix, ROC/AUC).

---

## Datasets

### 1. CIFAR-10 Dataset

-   **Description:** A collection of 60,000 32x32 color images in 10 classes, commonly used for image classification research.
-   **Source:** [CIFAR-10 Dataset on TensorFlow Datasets](https://www.tensorflow.org/datasets/catalog/cifar10) or via `keras.datasets.cifar10`.
-   **Note:** This dataset is typically downloaded automatically by Keras/TensorFlow libraries.

### 2. Intel Image Classification Dataset

-   **Description:** A dataset of natural landscape images with 6 classes (Buildings, Forest, Glacier, Mountain, Sea, Street).
-   **Source:** [Intel Image Classification Dataset on Kaggle](https://www.kaggle.com/datasets/puneet6060/intel-image-classification)
-   **Note:** This dataset should be downloaded manually and placed in a designated folder. Do **not** commit the dataset files to this repository. See [How to Run](#how-to-run) for details.
